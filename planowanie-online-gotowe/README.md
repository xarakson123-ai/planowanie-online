# Planowanie Online v3

Poprawki:
- zagrywanie karty identyfikowane jest unikalnym ID, więc karta z ręki nie powinna być odrzucana jako „nie masz tej karty”;
- kliknięcie legalnej karty zagrywa ją od razu;
- animacja tasowania i rozdawania na początku każdej rundy;
- kartka wyników pozostaje na stole;
- dla 3 graczy start to 16 kart;
- dla 4 graczy 12 kart, ponieważ po wyjęciu odkrytego atutu z talii nie da się rozdać pełnych 13 kart każdemu; dzięki temu rozdanie jest faktycznie równe.
