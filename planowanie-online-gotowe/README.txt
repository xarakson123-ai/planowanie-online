PLANOWANIE - GitHub Pages

1. Wrzuć folder docs oraz plik .nojekyll do repozytorium GitHub.
2. GitHub -> Settings -> Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /docs.
5. Save.
